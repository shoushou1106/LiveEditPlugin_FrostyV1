# Live Edit Plugin for Frosty v1
Editor only plugin for [Frosty Toolsuite v1](https://github.com/CadeEvs/FrostyToolsuite) to edit game in real time by editing their memory.

## About
This is a unfinished project I started in Late 2023, should be my first plugin for Frosty. Most part of progress are a UI panel, as my intro to WPF. I learned a lot while developing this project. But it contains no real logic. I haven't done any core logic to edit game in real time, and do not know how to do it, mostly a daydream since I saw someone did it.
